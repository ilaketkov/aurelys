# Ярлык

Веб-приложение (PWA) для iPhone: как вернуть российские приложения, удалённые из App Store —
Сбер, Т-Банк, Альфа, ВТБ, Газпромбанк, MAX, ВКонтакте, VK Мессенджер, Одноклассники, Дзен,
VK Видео, VK Музыка, Почта Mail.ru.

Для каждого приложения — статус, веб-версия в один тап и ранжированные **официальные** способы
установки (утилиты «Верни Сбер на iPhone» и T-Mazing, временный Apple ID от поддержки Т-Банка,
офис/курьер, восстановление из «Покупок», встроенная «Почта» iOS по IMAP).

Приложение сознательно не раздаёт IPA-файлы: iOS не ставит приложения в обход App Store
(кроме магазинов ЕС), «сторонние магазины» на корпоративных сертификатах Apple отзывает,
а модифицированные банковские сборки — основной инструмент мошенников.

## Как установить на iPhone

1. Опубликуйте папку `ru-apps/` на любом HTTPS-хостинге. Проще всего GitHub Pages:
   *Settings → Pages → Deploy from a branch*, выберите ветку и папку `/ (root)`;
   приложение будет по адресу `https://<логин>.github.io/aurelys/ru-apps/`.
2. Откройте адрес в Safari → «Поделиться» → «На экран „Домой“».

Работает офлайн (service worker кэширует инструкции).

## Как обновить данные

Весь каталог — массив `APPS` в `index.html`. У каждого приложения: статус, ссылка на веб-версию,
официальный сайт и список способов (`best: 1` — рекомендуемый). После правок увеличьте
`CACHE` в `sw.js` (`yarlyk-v2` …), чтобы у установленных копий обновился кэш.
