# Вернуть — приложение для iPhone

Нативное приложение на SwiftUI (iOS 16+). Каталог российских приложений, удалённых из App Store
(Сбер, Т-Банк, Альфа, ВТБ, Газпромбанк, MAX, VK, ОК, Дзен, VK Видео, VK Музыка, Почта Mail.ru),
с официальными способами вернуть каждое: веб-версия во встроенном браузере, утилиты банков,
офис и курьер, инструкции и предупреждения о мошеннических сборках.

Приложение не скачивает чужие IPA: iOS позволяет ставить приложения только App Store.

## Где взять .ipa

GitHub Actions собирает приложение на каждый push (workflow `iOS-приложение`):
- после мержа в `main` файл `Vernut.ipa` лежит в релизе **latest** (Releases справа на странице репозитория);
- для любой ветки — в артефакте `Vernut-ipa` на странице запуска в Actions.

Файл не подписан. Подпись ставится при установке вашим Apple ID.

## Установка на iPhone (Windows или Mac)

1. Установите **Sideloadly** с сайта sideloadly.io. На Windows также нужны iTunes и iCloud
   с сайта Apple (не из Microsoft Store).
2. Подключите iPhone кабелем и нажмите на телефоне «Доверять этому компьютеру».
3. Перетащите `Vernut.ipa` в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
5. iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить,
   перезагрузить.

Бесплатный Apple ID подписывает приложение на **7 дней**. Потом повторите шаг 3
(в Sideloadly можно включить автоматическое продление по Wi-Fi). С платным аккаунтом
разработчика ($99/год) подпись действует год, и приложение можно раздавать через TestFlight.

## Сборка на Mac

```sh
brew install xcodegen
cd ios && xcodegen generate && open Vernut.xcodeproj
```

В Xcode: Signing & Capabilities → Team → ваш Apple ID, выберите iPhone и нажмите ▶.

## Как обновить данные

Каталог — массив `Catalog.apps` в `Vernut/Catalog.swift`. После правок обновите `Catalog.checkedAt`.
